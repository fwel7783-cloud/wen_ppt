PRESENTASI WEBSITE ONLINE

Isi folder:
- index.html  : struktur dan isi slide presentasi
- style.css   : desain/tampilan presentasi
- script.js   : navigasi dan interaksi slide

CARA UPLOAD KE INFINITYFREE
1. Ekstrak file ZIP ini.
2. Login ke akun InfinityFree dan buka Control Panel situs.
3. Buka File Manager.
4. Masuk ke folder htdocs.
5. Upload index.html, style.css, dan script.js ke dalam htdocs.
   Pastikan ketiganya berada langsung di htdocs, bukan di dalam folder tambahan.
6. Buka alamat subdomain website Anda melalui browser.
7. Jika halaman lama masih muncul, refresh browser atau bersihkan cache.

CATATAN
- Ini adalah presentasi frontend statis, jadi tidak membutuhkan database MySQL atau PHP.
- Jangan mengubah nama file atau lokasi CSS/JS kecuali tautannya di index.html juga diubah.
- Untuk dibagikan ke orang lain, kirim alamat subdomain/website setelah berhasil diunggah.
