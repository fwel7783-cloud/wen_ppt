Materi presentasi01
01 · Pengantar

Apa itu website?

Website adalah kumpulan halaman digital yang saling terhubung dan dapat dibuka melalui browser menggunakan alamat web. Website dapat berisi informasi, gambar, video, formulir, maupun fitur interaktif.

Website statis

Konten relatif tetap. Umumnya dibuat menggunakan HTML, CSS, dan JavaScript.

Website dinamis

Konten dapat berubah berdasarkan data atau aktivitas pengguna, biasanya melibatkan bahasa pemrograman sisi server dan database.

Dasar-dasar website02
02 · Teknologi dasar

HTML, CSS, dan JavaScript

HTML — struktur

Menentukan susunan dan isi halaman, seperti judul, paragraf, gambar, tautan, dan formulir.

CSS — tampilan

Mengatur warna, ukuran teks, jarak, tata letak, animasi, dan responsivitas halaman.

JavaScript — interaksi

Membuat halaman merespons tindakan pengguna, misalnya tombol, validasi formulir, dan navigasi.

CDN — sumber pustaka

Content Delivery Network dapat digunakan untuk memuat pustaka atau aset dari jaringan server, contohnya Bootstrap atau ikon.

03 · Alur publikasi

Dari web lokal menjadi online

Website yang selesai dibuat di komputer perlu diunggah ke layanan hosting agar dapat diakses melalui internet.

Buat website→Hosting→Domain→Online

Gambaran proses

Siapkan file website dan database, pilih layanan hosting, unggah file, hubungkan database jika diperlukan, atur domain atau subdomain, lalu uji website melalui browser.

Alur kerja publikasi04
04 · Hosting

Apa itu hosting?

Hosting adalah layanan penyimpanan dan penyediaan sumber daya server untuk menyimpan file website agar dapat diakses melalui internet.

Fungsi hosting

Menyimpan file website, menjalankan aplikasi web, dan menyediakan akses bagi pengunjung.

Contoh isi hosting

File HTML, CSS, JavaScript, PHP, gambar, serta file pendukung website.

Analogi: hosting seperti tempat atau bangunan untuk menyimpan dan menjalankan website.

Konsep hosting05
05 · Alamat website

Domain dan subdomain

Domain

Nama/alamat yang digunakan untuk mengakses website, misalnya contoh.com.

Subdomain

Bagian tambahan di depan domain utama, misalnya blog.contoh.com atau namasitus.infinityfreeapp.com.

Perbedaannya

Domain adalah alamat utama. Subdomain merupakan alamat turunan yang dapat diarahkan ke bagian atau website tertentu.

Analogi: domain seperti alamat utama, sedangkan subdomain seperti bagian atau unit di dalam alamat tersebut.

06 · Database

Mengenal MySQL

MySQL adalah sistem manajemen basis data relasional (RDBMS) yang digunakan untuk menyimpan, mengatur, dan mengambil data menggunakan SQL.

Contoh data

Data akun pengguna, daftar barang, informasi produk, komentar, dan riwayat transaksi.

Hubungan dengan website

Aplikasi server dapat membaca atau menyimpan data ke MySQL berdasarkan permintaan dari website.

Contoh perintah SQL:
SELECT * FROM pengguna;
Database website07
07 · Publikasi

Website public

Website public adalah website yang dipublikasikan sehingga dapat diakses oleh orang lain melalui jaringan internet, sesuai pengaturan aksesnya.

HTML publik

Halaman HTML dapat ditampilkan oleh browser setelah file tersedia di server web.

Akses pengguna

Pengunjung membuka alamat website melalui browser. Jika website memiliki login, akses fitur dapat dibatasi berdasarkan akun atau peran.

Catatan: “public” berarti dapat diakses melalui internet, bukan berarti semua data dan halaman harus terbuka untuk umum.

08 · Pilihan pengerjaan

Website untuk individu atau satu kelas

Individu

Dibuat dan dikelola oleh satu orang. Cocok untuk portofolio, profil, atau proyek pribadi.

Satu kelas

Dapat menjadi proyek bersama. Pembagian tugas dapat meliputi desain, frontend, backend, database, dan dokumentasi.

Kerja kelompok membutuhkan pembagian tanggung jawab, kesepakatan fitur, dan pengujian bersama.
